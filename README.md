# SAYMA BUILDERS Unified Android App

One Android app for Admin and Worker. It opens the common role-aware login page and routes each account to its own mobile portal. See `README-UNIFIED-APP-BANGLA.txt` for setup, offline behaviour, GPS/camera permissions, downloads, and GitHub Actions build steps.

- Package: `com.saymabuilders.mobile`
- Version: `1.2.0` (`versionCode 4`)
- API: `https://saymabuilders.com/portal/api.php`
- Single login: `https://saymabuilders.com/portal/login.html`
