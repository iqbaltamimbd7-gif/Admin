============================================================

Mobile Admin:  https://saymabuilders.com/portal/mobile/

Shared API:    https://saymabuilders.com/portal/api.php
Admin Login:   https://saymabuilders.com/portal/login.html?next=mobile

ADMIN ANDROID APP
-----------------
The app now opens the current Admin login route and then the current Mobile Admin route.
The Android WebView host allow-list and offline asset interception prefix now match
saymabuilders.com and /portal/mobile.

The mobile app's API path is forced to the same-origin absolute /portal/api.php route.
This resolves to /portal/api.php on the same HTTPS origin and prevents an old
localStorage API path from pointing back to the previous Admin subdomain.

OFFLINE IMPLEMENTATION
----------------------
The existing Admin offline implementation was preserved:
- IndexedDB state snapshot and pending sync queue
- Existing merge and conflict handling
- Existing attachment/document offline cache and queue
- Existing Service Worker public-shell cache policy
- Existing login/session cookie handling
Only the URL constants, production API path migration and static shell cache version
were changed.

BACKEND
-------
No PHP, SQL schema, database credentials or server config are bundled in this Android
app source package. The app uses the existing server-side /portal/api.php endpoint.
Profile and reminders continue to resolve relative to /portal/api.php as before.

VALIDATION
----------
Static source checks are included. Live login, PHP session, MySQL, upload, and actual
Android offline/online behaviour must still be tested on the live hosting and phone.
